# Iris

一个围绕角色、对话与故事展开的交互原型。

## 使用

在浏览器中打开 `index.html` 即可运行，无需安装依赖。

## 数据与连接

- 用户资料、角色资料与对话保存在当前浏览器的本地存储中。
- AI 对话需要在应用设置中配置兼容 OpenAI 的 API。
- 聊天中的转账是虚拟互动，不会产生真实支付。

## 仓库结构

- `index.html` 和 `style.css` 是 GitHub Pages 的网页入口与样式。
- `scripts/` 放应用模块与启动加载器。
- `assets/` 放图片、字体和静态数据；界面图片优先使用 WebP。
- `config/` 放 PWA 清单和当前版本信息；根目录的 `version.json` 为兼容已缓存旧版清单的手机保留。
- `tests/` 放本地自动化检查。

## 香水店经营

从底部更多功能进入 **Business**，可选择当前面具绑定的角色作为经营伙伴，也可单人开店。开店后能在店铺首页随时更换伙伴或切换单人经营；已购藏品会保留购入时的分红参与者。本金从该面具的人民币钱包投入，每个面具独立保存店铺。

- 货源：主动寻访生成 NPC 卖家与香水；检查线索、邀请角色判断、议价后决定是否购入。
- 收藏室：已购香水可送专业鉴定，按已披露结果联系买家；仿品和改装品按样本价值交易。
- 调香台：邀请角色围绕一个主题共同构思，调整香调和瓶型，制作后入藏并可请角色试香。
- 账本：先扣除购入与检查等成本，再将参与交易的正净利润按店主 60%、参与角色合计 40% 分配；没有伙伴或角色参与时，利润归店主。未建立的角色钱包会保留待领取分红；其他币种领取时使用现有汇率服务。

“经营”可单独分配 API，未分配时沿用线上聊天配置。货源、检查、角色意见、买家报价及调香草稿都在本机保存，查看已有资料不重复请求 API。店铺包含在备份的“商场与香水店”分类中。
